# Matriz de Atribuições

Abaixo detalhamos as responsabilidades de cada membro para o desenvolvimento do REA (Recurso Educacional Aberto) sobre Acessibilidade Web.

| Integrante | Papel Principal | Atribuições Específicas |
| :--- | :--- | :--- |
| **Aluno(a) 1** | Desenvolvedor(a) Front-End | Implementação do código da página (HTML semântico, CSS, JavaScript). Responsável por programar as seções interativas que demonstram a acessibilidade na prática. |
| **Aluno(a) 2** | Designer de IHC / UI | Prototipação das telas (ex: usando Figma), definição da arquitetura de informação, e garantia de que o design visual seja acessível (contraste adequado, fontes legíveis). |
| **Aluno(a) 3** | Produtor(a) Audiovisual | Roteirização, gravação e edição das videoaulas curtas (5 a 7 minutos). É responsável por garantir os recursos de acessibilidade no vídeo, como a inserção de legendas. |
| **Aluno(a) 4** | Scrum Master | Gestão do cronograma ágil utilizando o Trello (Kanban), organização das Sprints, e realização de testes de acessibilidade na página. |
| **Aluno(a) 5** | Redator(a) de Conteúdo Textual | Responsável por pesquisar e escrever a descrição teórica do tema em formato de página web, garantindo a linguagem lúdica e simplificada para a comunidade externa. |

*Nota: Apesar das atribuições específicas, todos os cinco membros participarão das discussões gerais, pesquisa de viabilidade tecnológica e testes finais de acessibilidade. Está sujeito a mudanças na atribuição das funções de acordo com a disponibilidade de cada integrante do grupo. Mais funções serão adicionadas ao decorrer do desenvolvimento do projeto, para cumprir com os requisitos e adições futuras. Um integrante pode participar de uma ou mais funções de acordo com sua disponibilidade.*
