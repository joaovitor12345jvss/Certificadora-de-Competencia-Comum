## Sobre o Projeto
A internet deve ser um espaço onde todas as pessoas possam navegar, aprender e interagir sem barreiras. Este projeto tem como objetivo ensinar os conceitos fundamentais de Acessibilidade Web, unindo fundamentos de Front End e Interação Humano-Computador (IHC). 

Nosso foco é demonstrar, na prática, como criar páginas web que sejam inclusivas para pessoas com diversas deficiências e necessidades (como deficiência visual, daltonismo e dislexia), abordando a construção de sites através de duas lentes: o **Design** e o **Código**.

## Público-Alvo
Em conformidade com o caráter extensionista do projeto, nosso material é voltado para a comunidade externa, especialmente pessoas sem formação técnica superior na área de TI. Todo o conteúdo foi planejado para ter uma abordagem lúdica e simplificada, evitando jargões complexos e facilitando o aprendizado de iniciantes.

## O que vamos ensinar?
O projeto demonstrará que a acessibilidade é um trabalho em conjunto:
*   **No Design (IHC):** Como o uso adequado de contraste de cores, tamanhos de fonte, espaçamentos e organização visual facilita a navegação e a experiência do usuário.
*   **No Código (Front End):** Como a utilização do HTML semântico (como as tags corretas para botões e links) e descrições de imagens (textos alternativos) permitem que tecnologias assistivas, como leitores de tela, leiam e interpretem a página corretamente.

## Estrutura do Recurso Educacional Aberto (REA)
Este projeto será estruturado da seguinte forma:
*   **Página Web Interativa (Conteúdo Textual):** Uma página web servirá como base teórica, apresentando os conceitos de forma visual e guiada.
*   **Videoaulas:** Pílulas de conhecimento em formato de vídeos curtos (5 a 7 minutos), projetados obrigatoriamente com recursos de acessibilidade, como legendas.
*   **Prática de Código Integrada:** O ensino de código não será isolado. O usuário poderá comparar e testar trechos de código acessível versus inacessível diretamente como parte integrante da aula. Utilizando de gamificação para aprender na prática bons hábitos para projetar páginas web de maneira acessivel para todos.
